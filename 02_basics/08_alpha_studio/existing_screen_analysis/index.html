    기존 화면 분석법¶

    신규 투입자가 가장 빠르게 개발 규칙을 배우는 방법은 정상 동작하는 기존 화면을 하나 선정해 끝까지 추적하는 것입니다.

    1. 화면 진입 시 실행되는 코드 찾기¶

    초기화 이벤트를 찾아 다음 항목을 기록합니다.

    • 기본값 설정
    • 공통코드 로딩
    • 버튼 활성/비활성
    • 사용자 권한 적용
    • 자동 조회 여부

    2. 조회 버튼 이벤트 추적¶

    btnSearch_Click
   ↓
ValidateSearch
   ↓
SetSearchData
   ↓
gfnTransaction(?)
   ↓
Callback
   ↓
BindGrid

    위와 같은 호출 흐름을 실제 함수명으로 적습니다.

    3. 서버 호출의 핵심 정보 기록¶

    서버 호출부에서는 다음을 확인합니다.

    • 서비스/거래 ID
    • 입력 데이터셋 이름
    • 출력 데이터셋 이름
    • 동기/비동기 여부
    • 콜백 함수명
    • 오류 메시지 처리 위치

    4. 그리드 사용법 수집¶

    그리드 API를 처음부터 모두 외우지 말고 실제 사용 예제를 목적별로 모읍니다.

    행 개수 얻기
셀 값 읽기
셀 값 쓰기
행 추가
행 삭제
선택 행 확인
그리드 초기화

    나만의 API 사전 만들기

    프로젝트 소스에서 확인한 실제 API만 Markdown 표에 누적하세요. 일주일만 지나도 개발 속도를 크게 높여주는 프로젝트 전용 치트시트가 됩니다.

    5. 저장 화면으로 확장¶

    조회 화면을 이해한 후 저장 화면을 분석하면 입력 데이터 구성, 변경 상태, 확인 메시지, 저장 후 재조회 같은 추가 규칙을 자연스럽게 배울 수 있습니다.
