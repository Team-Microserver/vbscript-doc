# 기본 문법 개요

VBScript의 기본 문법은 겉보기에는 단순하지만, Java처럼 정적 타입 언어에 익숙한 개발자에게는 몇 가지 중요한 차이가 있습니다. 특히 모든 일반 변수가 `Variant` 기반으로 동작한다는 점, 블록을 중괄호가 아니라 `End If`, `Next`, `End Sub` 같은 키워드로 닫는다는 점을 먼저 익혀야 합니다.

## 기본 코드 구조

```vb
Option Explicit

Dim amount
Dim customerName

amount = 10000
customerName = "KIM"

If amount > 0 Then
    MsgBox customerName & " / " & amount
End If
```

코드를 읽을 때는 문법 이름보다 **실행 순서**를 먼저 보는 것이 좋습니다.

1. 변수 선언
2. 값 할당
3. 조건 평가
4. 조건을 만족하면 명령 수행

!!! tip "Java 개발자 관점"
    VBScript는 타입 정보가 코드에 거의 드러나지 않습니다. 따라서 변수 이름과 값이 어디서 들어오는지를 추적하는 습관이 Java보다 더 중요합니다.

## 주석

작은따옴표 `'` 뒤는 주석입니다.

```vb
Dim accountNo    ' 계좌번호
accountNo = "1234567890"
```

`Rem`도 사용할 수 있지만 실무에서는 `'`가 훨씬 흔합니다.

## 한 줄에 여러 명령 작성

콜론 `:`을 이용해 한 줄에 여러 명령을 작성할 수 있지만 가독성이 떨어지므로 권장하지 않습니다.

```vb
Dim a : a = 10 : MsgBox a
```

!!! warning "레거시 코드 읽기"
    오래된 코드에서는 위와 같은 축약형을 만날 수 있습니다. 새 코드를 작성할 때는 가능한 한 한 줄에 하나의 명령을 두는 편이 좋습니다.
