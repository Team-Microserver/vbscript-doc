# 참고 자료

이 가이드의 언어 문법은 일반적인 VBScript 문법과 Windows Script 계열의 개념을 기준으로 작성했습니다.

## 권장 참고 방향

- Microsoft Learn의 VBScript/Windows Script 관련 문서
- 실제 프로젝트의 정상 동작 화면 소스
- 프로젝트 공통 스크립트/공통 함수 정의
- 알파로스튜디오 프로젝트 내부 도움말 또는 사내 개발 표준(제공되는 경우)

!!! important "실제 프로젝트에서는 내부 표준 우선"
    전용 화면 플랫폼의 이벤트명, 컨트롤 속성, 데이터셋 API, 서버 호출 방식은 프로젝트 구현에 따라 달라질 수 있습니다. 이 가이드의 플랫폼 관련 예시는 구조를 이해하기 위한 개념 예시이며 실제 API 명세가 아닙니다.

## 학습 자료 활용 원칙

외부 VBScript 문법 자료에서 얻은 예제를 실제 금융 단말에 그대로 적용하기보다, 먼저 프로젝트 실행 환경이 해당 객체나 기능을 지원하는지 확인하세요. 특히 파일 접근, 로컬 COM 객체, 네트워크 객체는 보안 정책상 제한될 수 있습니다.
